# RUBRIC PROCESS

*We replaced the old method of "dividing the total work in five activities and in 100 points" with a brand new method that uses scrum artifact "definition of done". previously all five activities had a value for the project, they were the body, but now its not important, because we used the repository project issues to asign task to the members, so the contribution is measured in the amount of asigned tasks they complete.*

*Inside every issue, there is a definition of done that describes the criterias needed to deliver the task. members can deliver anything, but the artifact is going to decide if its correct or not, every criteria has a value of 10 points, if the work properties achieve the criteria, the responsible member will gain those points. if the max value of the task matches the member credited value, the task is complete.*

*Now the points that the members must achieve are always changing because of the new tasks they are asigned to, and they must complete all the criterias to gain complete contribution, the scale comes from multiplying the credited points by 100 and then dividing the result by all the points they must had completed.*
