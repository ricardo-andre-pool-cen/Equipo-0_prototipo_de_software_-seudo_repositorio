# NEW REQUIREMENTS

- **US_01**: *As a beginner user learning git navigating in the environment, i want a search button in the interface so i can quickly find any content available in the environment*

  - **Acceptance criteria:**
    - The search button is in the first page of the environment.
    - The search takes the user directly to the matched content.
    - Has graphic content

- **US_02**: *As a beginner user learning git navigating in the environment, i want to see graphic content about the git commmand "git init" so i can understand it's usage.*

  - **Acceptance criteria:**
    - It has all information about "git init"
    - There are examples of usage
    - There is graphic content or images as main format.
    - The information is presented as audio playables.

- **US_03**: *As a beginner user learning git, i want to see graphic content about the git commmand "git config" so i can understand it's usage.*

  - **Acceptance criteria:**
    - It has all information about "git config"
    - There are examples of usage
    - There is graphic content or images as visual help.
    - The information is presented as audio playables.

- **US_04**: *As a beginner user learning git, i want to see a comparison between a local repository config and a public repository config so i can learn how and when to use those functions*

  - **Acceptance criteria:**
    - There is graphic for the comparison.
    - The differences between advantages and disadvantages are clear.
    - There are examples of usage of both features.
    - The information is presented as audio playables.
