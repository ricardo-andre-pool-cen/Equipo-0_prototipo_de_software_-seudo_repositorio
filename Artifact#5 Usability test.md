# THE USABILITY TEST

## USABILITY ATTRIBUTES

Attribute | Description | Metric
--------- | ----------- | ------
navigation | The user can find all the articles and move among them | Amount of steps: opened articles, used tools
comprehension | The user can comprehend the information organization | Order of steps: correspondency to use cases diagram

We will also be counting the amount of doubts the user could have.

## SCRIPT

We will be looking for people in the FMAT, near the library, or even inside the library, so we can take them as quickly as posible to our test area.

We will have a computer ready with the prototype already open and recording the screen, we will also record the conversation with only audio.

Common introduction to request a person to be our tester: *"Lamento la molestia, estoy buscando voluntarios para una actividad relacionada a la clase de Fundamentos de la Ingenieria de Software, esta actividad tiene como duracion maxima 20 minutos, ¿Te gustaría participar?"*.

First and unique question: *"Do you know git?"*

Common introduction to start the activity *"Como parte de las enseñanzas de esta clase, creamos un prototipo no funcional de un sitio web que trata sobre nuevos metodos para ayudar a los usuarios a comprender git (en caso de que el usuario conozca git). El objetivo de la actividad es simular una evaluacion de la calidad de nuestro prototipo, solamente con el enfoque de usabilidad, es decir, la experiencia que el usuario siente usando el prototipo, tu deber es seguir el curso de la prueba ya preestablecida, completando las tareas que se te asignen"*.

The usability test is going to be taken with the tool "Ballpark". The main tasks of our test is to complete the knowledge tests of our article, everythin is writted down in the "Ballpark" usability test service.

## RESULTS

Our main mistake that we did for the usability test, was that the people who tested our protoype weren't our users but just some of the friends of the members, they didn't even know what git was.

The second mistake has to do with the prototype, they were told that the objective of it was to provide information about git in different style formats than just text in order to the users to comprehend it better, so they were expecting the real information in the protoype, and they didn't find anything, they just got a disappointment.
