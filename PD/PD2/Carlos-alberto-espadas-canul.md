# Requerimiento Funcional

-- Sistema de Mensajeria--
--Equipo 3--
El usuario cuenta con una mensajeria para mandar y recibir mensajes

  Historia de Usuario
-El usuario puede acceder al sistema de mensajeria
-El usuario puede seleccionar un contacto de su lista
-El usuario cuneta con un boton para enviar mensajes
-El sistema muestra una configuracion que el mensaje se haya enviado correctamente

 Criterios de Aceptación

Visualizacion de contactos
-El usuario cuenta con la opcion de visualizar a sus contactos.
-El usuario puede visualizar el nombre y foto de perfil del contacto.

 Seleccion de contacto
-Al momento de seleccionar un contacto , se abrira una ventana correspondiente.

 Escritura de Mensaje
-El usuario cuenta con un cuadro de texto para escribir.

Envio de Mensaje

- El usuario cuenta con un boton enviar o presionando "Enter".
- Si el mensaje esta vacio, el boton "Enviar" debe estar desabilitado.

 Entrega de Mensaje
-El mensaje enviado debe aparecer con una marca de tiempo.

 Conectividad
-El mensaje se envia automaticamente cuando el usuario esta conectado a una red.
